🛩️ OACA Agents - Guide Accès Public Mondial

🎯 Objectif

Rendre votre application OACA Agents accessible depuis n'importe où dans le monde via Internet.

📋 ÉTAPE 1 : Création du compte ngrok (GRATUIT)

1. Cliquez sur le bouton ci-dessous pour créer un compte gratuit :

🌐 Créer un compte ngrok

2. Utilisez votre email pour vous inscrire

3. Confirmez votre email si demandé

4. Connectez-vous à votre nouveau compte

🔑 ÉTAPE 2 : Récupération du token

1. Une fois connecté, cliquez ici pour obtenir votre token :

🔑 Obtenir mon token

2. Copiez le token qui commence par "2..." (environ 50 caractères)

Exemple : 2ABC123def456ghi789jkl012mno345pqr678stu901vwx234yz

🚀 ÉTAPE 3 : Lancement automatique

1. Double-cliquez sur le fichier :

RENDRE_PUBLIC_AUTOMATIQUE.bat

2. Suivez les instructions à l'écran

3. Collez votre token quand demandé

4. Votre application sera automatiquement accessible publiquement !

⚠️ Important - Sécurité

Une fois public, votre application sera accessible depuis n'importe où !

  • 🔐 Identifiants actuels : admin@oaca.tn / admin123
  • 🛡️ Changez ces identifiants si nécessaire
  • 👥 Partagez l'URL uniquement avec les personnes autorisées
  • 📊 Surveillez les accès via le dashboard ngrok

🎉 Résultat final

Après configuration, vous obtiendrez une URL comme :

https://abc123.ngrok.io

Cette URL sera accessible depuis :

  • 🌍 N'importe quel pays
  • 📱 Tous les appareils (PC, mobile, tablette)
  • 🌐 Tous les navigateurs
  • 🔒 Connexion HTTPS sécurisée

🚀 Prêt à rendre votre application publique ?
